设计要点

  • 列容器用浅灰底 #eff0ec + 圆角 12px，卡片白底浮在其上 —— 靠「底色分层」而不是边框堆叠产生深度
  • 列头：状态点 + 大写字距标签 + 等宽字体计数徽章；Working 的点带柔和呼吸动画（唯一动效，可删）
  • 卡片信息分三段：会话 ID（等宽、小号）→ 摘要两行截断 → 底部元信息（模型 chip + 统计 + 时间右对齐）
  • 悬停只做 translateY(-1px) + 极淡投影，无缩放无发光
  • Needs you 有待办时卡片右侧带琥珀色 flag，Finished 为空时用虚线占位而非空白
  • 进度条：仅在 todo 进行中时渲染（Working / Needs you），3px 圆角轨道 + tabular 等宽计数；进行中为绿色，等待用户时为琥珀色，Idle / Finished 不显示
  • 数字一律 tabular-nums，避免等宽跳动
